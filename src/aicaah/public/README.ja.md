# AICAAH 0.1 ベータ

**AI Coding Agent Architecture Harness**。コード・設計文書・プロジェクト構造の整合性を検査する共通ハーネスです。MIT ライセンス。

Python、C#、JavaScript、TypeScript、Java、Go のソース構造を読み取ります。フォルダー、モジュール、クラス、インターフェース、関数、変数の上限は利用者が設定します。対象言語のプログラムや SDK を実行・インストールしません。

Python 3.10 以降が必要です。現在は PyPI 公開前の配布準備版です。ソース配布フォルダーで `python -m pip install .` を実行するか、配布 wheel をインストールしてください。その後、検査対象プロジェクトへ移動します。

```sh
aicaah
```

ウィザードで選択した内容は `aicaah.json` に保存されます。再実行しても既存設定を上書きしません。インストールは既存の作業モードを保持します。コードマップでコードまたは承認済み設計を基準とするモードを選択できます。文書化されていないコードは引き続き指摘対象です。

左側の共通コードグラフと、右側の指摘・実装タブを使用します。停止は `aicaah stop`、インストール検査は `aicaah selftest --portable` です。コマンドが見つからない場合は `python -m aicaah` を使用できます。

表示言語は英語・韓国語・中国語・日本語です。一部の高度な診断と文書プロトコル見出しは韓国語のままです。意味参照解析の対応範囲は言語により異なります。インストールでエージェントフックの信頼設定を自動変更しません。

## 番号選択のセットアップ

`aicaah` を実行し、表示言語 → プロジェクトフォルダー → ソース言語 → 検査フォルダー → モジュール境界 → 構造の個数制限 → 確認してインストールの順に番号で選択します。フォルダーを番号で移動し、制限は単位・集計対象・範囲・深さを選んで上限の数値を入力します。言語オプションや設定式は不要です。メニューの 0 は戻る、-1 は中止です。上限の 0 は有効です。最後の確認まではファイルを変更せず、既存の設定を保持します。完了後、選択したプロジェクトで `aicaah ask status` を実行し、表示された URL を開いて作業モードを選択してください。
