# AICAAH 0.1 베타

**AI Coding Agent Architecture Harness** — 코드·문서·프로젝트 구조를 대조하는 공용 하네스. MIT 라이선스.

Python, C#, JavaScript, TypeScript, Java, Go의 소스를 읽어 폴더·모듈·클래스·인터페이스·함수·변수 구조를 검사합니다. 대상 프로그램을 실행하거나 언어별 SDK·개발 환경을 설치하지 않습니다. 사용자가 정한 경계와 수량 한도가 중심입니다.

## 설치

Python 3.10 이상이 필요합니다. 현재는 공개 배포 준비본이며 PyPI 업로드 전에는 `pip install aicaah`로 설치되지 않습니다. 소스 배포 폴더에서 다음을 실행합니다.

```sh
python -m pip install .
```

wheel 파일을 받았다면 `python -m pip install ./aicaah-0.1-py3-none-any.whl`을 사용합니다. 이후 검사할 프로젝트 폴더로 이동합니다.

```sh
aicaah
```

터미널에서 번호를 선택하며 설치합니다.

1. 표시 언어에서 **2. 한국어**를 선택합니다.
2. 프로젝트 폴더를 번호로 탐색해서 선택합니다. 다른 경로를 직접 입력할 수도 있습니다.
3. 검사할 언어와 소스 폴더를 선택합니다.
4. 모듈 경계로 볼 폴더를 선택하거나 다음으로 넘어갑니다.
5. 개수 제한에서 단위와 항목을 선택합니다. 예를 들어 **폴더 → 파일 → 전체 검사 경로 → 직접 포함 → 12**를 입력하면 폴더당 파일 수를 12개로 제한합니다. 클래스·함수·변수·모듈 수도 같은 방식으로 추가합니다.
6. 요약을 확인하고 **확인 후 설치**를 선택합니다.

메뉴의 **0은 이전**, **-1은 취소**입니다. 최대 개수 입력에서는 0도 유효한 한도입니다. 마지막 확인 전에는 파일을 쓰지 않으며, 기존 설정은 보존합니다. 언어 옵션이나 설정 문법을 외울 필요가 없습니다. `aicaah init`도 같은 안내를 시작합니다.

설치 후 선택한 프로젝트 폴더에서 `aicaah ask status`를 실행하고 출력된 주소를 엽니다. 화면에서 작업 모드와 코드 수정 정책을 선택할 수 있습니다. 설치는 기존 승인·작업 모드를 유지합니다. 문서가 없는 코드도 지적 대상이므로 설치 직후 지적 0건을 보장하지 않습니다.

웹 화면은 공통 좌측 그래프와 우측 지적·구현 탭으로 구성됩니다. 설정 화면에서 직접 포함/하위 전체 집계, 폴더별 예외와 한도를 변경할 수 있습니다. 종료는 `aicaah stop`, 설치 검사는 `aicaah selftest --portable`입니다. 명령을 찾지 못하면 `python -m aicaah`를 사용하세요.

표시 언어는 영어·한국어·중국어·일본어입니다. 고급 진단과 문서 표의 기계 판독 키는 일부 한국어로 남습니다. 의미 참조 분석은 언어별 지원 범위가 다릅니다. 훅 자동 연결·신뢰 활성화는 설치에 포함되지 않습니다.
