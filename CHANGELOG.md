# Changelog

## 0.1 — Beta, prepared for first public release

- Official name: AICAAH — AI Coding Agent Architecture Harness.
- Python package, import and CLI name: `aicaah`; MIT license.
- Six-language source structure parsing with user-defined boundaries and count limits.
- English, Korean, Chinese and Japanese setup and common UI catalogs.
- Shared incremental source, check and derived-output caches.
- Clean source export, portable installation tests and reproducible public API benchmark.
- New projects use `aicaah.json`; existing `specconformance.json` remains supported in place.

The earlier development distribution used a different name and development version. This `0.1` is the first AICAAH public beta identity. Registry publication is a separate release step.

- Numbered terminal setup opens with `aicaah`: four display languages, folder browsing, module boundaries and numeric structure limits, with back/cancel and final confirmation.
